# AI Resume Builder

An intelligent resume building application powered by AI that helps users create, customize, and optimize their resumes with ease.

## Features

- **AI-Powered Resume Generation**: Leverage artificial intelligence to generate professional resume content
- **Customizable Templates**: Choose from multiple professionally designed resume templates
- **Real-time Preview**: View changes to your resume in real-time as you edit
- **Easy Export**: Download your resume in multiple formats (PDF, DOCX, etc.)
- **User-Friendly Interface**: Intuitive UI designed for seamless user experience

## Tech Stack

- **Frontend**: JavaScript (90.3%)
- **Styling**: CSS (9.5%)
- **Markup**: HTML (0.2%)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/vermaabhay32814-eng/AI-resume-builder.git
cd AI-resume-builder
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open your browser and navigate to `http://localhost:3000`

## Usage

1. **Create a New Resume**: Click on "Create New Resume" to start building your resume
2. **Fill in Your Details**: Enter your personal information, education, experience, and skills
3. **Use AI Assistance**: Leverage AI features to enhance your resume content
4. **Choose a Template**: Select from available resume templates
5. **Preview & Edit**: Review your resume and make any necessary adjustments
6. **Download**: Export your final resume
